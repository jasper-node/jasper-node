# JasperNode

[JasperNode](https://www.jasperx.com.au/) is an AI-based softPLC built for programming and running industrial control logic.

Creating new posts on [Issues page](https://github.com/jasper-node/jasper-node/issues) for bugs or feature requests is much appreciated. Feel free to react to the ones you'd like us to prioritise.

## Getting Started

Head over to [our website](https://www.jasperx.com.au/how-to-use/download) to download and try out on your PC with asking AI to simulate data for the connectors.
