# JasperNode

[JasperNode](https://jasperx.com.au/) is an AI-assisted industrial automation runtime for Linux.
Everything — I/O, control logic, configuration and system state — is a **tag** in one live
in-memory tree, configured through a browser IDE with a built-in AI agent. Any change that affects
the running process passes through a test-and-sign-off **Deploy Gate** before it goes live.

Creating new posts on the [Issues page](https://github.com/jasper-node/jasper-node/issues) for bugs
or feature requests is much appreciated. Feel free to react to the ones you'd like us to
prioritise.
