# JasperNode

JasperNode is the free controller runtime for [JasperX](https://jasperx.com.au/). It runs a
machine's logic around the clock, connects it to the field and to JasperX, and keeps running with
no internet. You build, test and manage it from JasperX in the browser.

- Product: [jasperx.com.au](https://jasperx.com.au/)
- Documentation and install: [jasperx.com.au/docs](https://jasperx.com.au/docs)

Bugs and feature requests are welcome on the
[Issues page](https://github.com/jasper-node/jasper-node/issues).
